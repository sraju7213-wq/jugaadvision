# Jugaad Visuals — Smart AI Creative Studio

An all-in-one toolkit for AI art prompt engineering. Create, analyze, manage, and
optimize prompts for leading AI image generators, with background removal,
vision analysis, and multi-provider model routing.

## Requirements

- Node.js 18+

## Run locally

```bash
npm install
npm run dev        # compiles Tailwind, then starts Vite
```

Open the URL Vite prints (default http://localhost:5173).

## Environment

Copy `.env.example` to `.env` and fill in the provider keys you use:

```bash
cp .env.example .env
```

| Variable | Purpose |
|---|---|
| `OPENROUTER_API_KEY_*` | OpenRouter keys (numbered or comma-separated) |
| `NVIDIA_NIM_API_KEY_*` | NVIDIA NIM keys |
| `HUGGINGFACE_API_KEY` | Hugging Face token (vision models) |
| `CLOUDFLARE_API_TOKEN` | Cloudflare Workers AI |
| `REMOVE_BG_API_KEY` | remove.bg (server-side only) |
| `PREFER_FREE_MODELS` | Prefer free models when routing |
| `AI_CACHE_TTL_MS` | AI response cache TTL |

Keys without a `VITE_` prefix stay server-side. Never commit `.env`.

## Scripts

| Script | What it does |
|---|---|
| `npm run dev` | Tailwind → `public/styles.css`, then Vite dev server (with `/api/*` handled in-process) |
| `npm run build` | Tailwind + bundle serverless API (`api-src/` → `api/`) + Vite build → `dist/` |
| `npm run preview` | Serve the production build locally |
| `npm run bundle:api` | Only rebundle the serverless API |
| `npm run build:android` / `build:apk` | Build + Capacitor sync / debug APK |

## Project layout

```
index.html            # Vite entry (loads /src/index.tsx)
src/                  # Frontend: App, components, pages, hooks, lib, services, css
server/ai/            # Backend: model router, adapters, registry, health, key pools
api-src/              # Vercel serverless sources (thin wrappers over server/ai)
api/                  # Generated bundles (regenerated by `npm run build`, git-ignored)
scripts/bundle-api.mjs# esbuild bundler for api-src → api
public/               # Static assets; styles.css is generated (git-ignored)
dist/                 # Production build output (git-ignored)
android/              # Capacitor Android shell
```

## Deploy (Vercel)

1. Add the server-side env vars from `.env.example` in
   Project Settings → Environment Variables (no `VITE_` prefix on secrets).
2. Deploy — `npm run build` regenerates `api/` automatically.
3. `vercel.json` handles SPA rewrites, cache headers, and function timeouts.
